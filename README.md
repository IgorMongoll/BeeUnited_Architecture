# Bee United Platform — Industry 4.0

Initial GitHub Pages architecture preview with approved sheets 02–05, clickable navigation and a link to [Bee United Production Server — development board](https://github.com/users/IgorMongoll/projects/3/views/2).

## Publish
1. Create a dedicated repository (suggested: `BeeUnited_Architecture`).
2. Upload `index.html` and the `assets/` folder to its default branch.
3. In repository **Settings → Pages**, select **Deploy from a branch**, your default branch, and `/ (root)`; save.
4. Wait for the Pages deployment and open the URL shown in Settings → Pages.

**Note:** The linked GitHub Project is private; only users with access can see its board. The site itself contains architecture diagrams and no progress statuses.
